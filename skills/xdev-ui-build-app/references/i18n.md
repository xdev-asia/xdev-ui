# Strings in en and vi

- `en.ts` exports `en` and its type `Dict`; `vi.ts` is typed `Dict`, so a missing key fails typecheck.
- `t("home.title")` looks up a dotted key; `{name}` placeholders take values: `t("users.selected", { count: 3 })`.
- `I18nProvider` holds the locale; pages call `useI18n()` for `t`, `ui`, `locale` and `setLocale`.
- Library parts ship English defaults. Pass `labels={ui.dataTable}` and so on from `xdev-ui-labels.ts`, one entry per part you use, in both languages.
- Sentence case, verbs for actions ("Create item"), no emoji, no exclamation marks. Say what happened and what to do next in errors.
- Format dates and numbers with `Intl` for the active locale.
- The audit rule `i18n-parity` fails when `en` and `vi` differ or a value is empty.
