# BrandMark

The xDev logo v9: a round-capped `×` plus the agent cursor. As a bare mark, an app tile, or the tile + wordmark lockup.

## Variants
| variant | look | use |
|---|---|---|
| `mark` | `×` in `--accent` (follows `color`), cursor in `--brand-agent` | app chrome, inline |
| `tile` | white `×` and orange cursor on `#2f62e6`, 16 grid, radius 3.5/16 | favicon, avatar, social |
| `lockup` | tile + "xDev" in Be Vietnam Pro 800 + orange cursor bar | site header, docs, README |

`size` is the mark or tile edge in px; the lockup wordmark is `size × 25/32`.

## Rules
- The cursor is always `--brand-agent` `#ff7a3d`. Only the `×` follows the surface colour.
- Keep clear space of at least half the mark's height on all sides.
- Never recolour the tile ground, outline the mark, or set the wordmark in another face or weight.
- Static files live in assets/Logos.
