# Kbd

Inline key or chord, set in mono, for shortcuts in menus, the palette footer and docs.

## Rules
- One `Kbd` per chord ("Ctrl+K"), or one per key when the keys are read separately.
- Use the platform's modifier names: Ctrl on Windows and Linux, ⌘ on macOS.
- Inside `Menu` items use the `chord` prop instead; it right-aligns the text.
